About This Project

This is a production-ready static website running in a Docker container using the lightweight Nginx Alpine base image.

  • ✅ Nginx Alpine (minimal footprint < 50MB)
  • ✅ Custom SPA routing configuration
  • ✅ Optimized caching headers
  • ✅ Gzip compression enabled
  • ✅ Security headers configured
  • ✅ Health check endpoint

Docker Best Practices

🔒 Secure

Running as non-root user with security headers enabled

⚡ Fast

Static asset caching with 1-year expiry and gzip compression

📦 Tiny

Alpine Linux base image keeps total size under 50MB

🎯 Production Ready

Health checks, error handling, and proper logging
